## 사실 요약

- **BUSINESS · 네이버 검색**: 이용자의 정보 탐색을 지원하는 검색 플랫폼을 제공한다.
- **BUSINESS · 네이버 지도**: 장소 탐색과 이동에 필요한 지도·길찾기 등 로컬 서비스를 제공한다.
- **PROBLEM · 검색 웹 성능**: 2024년 공개한 통합검색 사례에서 JavaScript 로딩 시점과 성능 알람을 개선하고 실험으로 사용자 영향을 확인했다.
- **PROBLEM · 장애 탐지 지연**: 2023년 검색 SRE 사례에서 순차 배치의 지표·알람 지연과 복잡한 관제 화면을 개선하는 문제를 다뤘다.
- **PROBLEM · AI UI 성능 측정**: 2026년 통합검색 AIB 사례에서 점진적 렌더링과 DOM 재구성 때문에 LCP가 체감 성능을 충분히 설명하지 못하는 문제를 분석했다.
- **TALENT · 사용자 가치**: 일의 방향을 사용자에게 두고, 수행 목적과 문제의 출발점을 계속 점검한다.
- **TALENT · 정보 공유와 협업**: 동료의 이견을 검토하고 업무 지식·히스토리·맥락을 충분히 공유한다.
- **TALENT · 자율과 책임**: 스스로 일을 정의해 실행하고 결과와 영향에 책임을 갖고 정직하게 일한다.
